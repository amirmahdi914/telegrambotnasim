# بات تلگرام خدمات

نسخه ساده‌تر قبلی بزرگ‌تر شده: پنل مشتری، پنل ادمین، دیتابیس SQLite، مدیریت گروه و تشخیص آهنگ.

## کارهایی که عمدا اضافه نشد

- بازیابی اکانت هک‌شده بازی یا شبکه اجتماعی
- ردیابی گوشی
- دانلود فیلم اینستاگرام و یوتیوب
- پیام خودکار به صاحب‌کار داخل گپ‌ها (خلاف قوانین تلگرام است)

بخش امنیت فقط خدمات قانونی مثل بررسی امنیت سایت، SSL، پشتیبان و سخت‌سازی است.

جستجوی پروژه از سایت کاریابی فقط به **ادمین** خبر می‌دهد و در دیتابیس ذخیره می‌شود. خود ادمین با صاحب کار حرف می‌زند.

## نصب

```bash
pip install -r requirements.txt
```

فایل `.env.example` را کپی کنید و اسمش را `.env` بگذارید:

```
TELEGRAM_BOT_TOKEN=توکن_بات
OWNER_CHAT_ID=آیدی_عددی_شما
```

آیدی عددی را از `@userinfobot` بگیرید.

اگر قبلاً توکن را داخل فایل پایتون گذاشته‌اید، از BotFather توکن را Revoke کنید و توکن تازه بسازید؛ توکن قدیمی لو رفته حساب می‌شود.

برای تشخیص آهنگ یک کلید رایگان از [audd.io](https://audd.io) بگیرید و در `.env` بگذارید:

```
AUDD_API_KEY=...
```

## اجرا

```bash
python bot.py
```

## استفاده

مشتری:

1. `/start`
2. سایت / اپلیکیشن / امنیت
3. انتخاب خدمت
4. شرح مشکل
5. شماره تلفن و آیدی تلگرام (اگر خالی باشد خطا می‌دهد)
6. شماره تماس شما برای پیگیری نمایش داده می‌شود: `09366602126`

ادمین:

- `/admin` پنل جدا برای سفارش، مشتری، پروژه و اخطار گروه
- `/done 12` سفارش ۱۲ را انجام‌شده می‌کند
- ثبت پروژه دستی با مشخصات صاحب کار

گروه:

1. بات را به گروه اضافه کنید
2. بات را ادمین کنید
3. دسترسی حذف پیام و Ban را بدهید

اسپم و فحش پاک می‌شود. بعد از ۳ اخطار کاربر اخراج می‌شود.

ویس یا فایل آهنگ را به بات بفرستید تا نام آهنگ را بگوید (دانلود غیرقانونی فایل آهنگ انجام نمی‌شود).
